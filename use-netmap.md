# Use NetMap

This section describes the workspaces in the NetMap application: what you see, who can use them, and how they behave. Start with the Interface Tour if you have just signed in, then open the page for the workspace you need.

## Before You Start

You need a running NetMap instance and a signed-in account. What you can see and change depends on your role; each page names the permission it needs.
