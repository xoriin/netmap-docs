# Devices And Icons

**Admin → Devices & Icons** is where you manage device types, their colours and icons, and the colours of groups and locations. You need `device_catalog_manage`.

## Summary

- **Devices by Type** ranks device types by how many devices use each one.
- **Device Types** counts all types and the devices assigned, **Built in** and **Custom** list each kind, and **Icon pack** names the active pack.

## Device Types

**Type Library** lists each type with its **Colour** and **Default icon**. NetMap has 17 built-in types, which you can recolour but can't rename or delete.

To add a type, enter a **Device type** name in **New Device Type**, such as UPS or PDU, choose a **Default icon** and select **Add type**. You can edit or delete custom types from the library.

Each type has an automatic colour until you choose one. Select the reset button beside a colour to return to the automatic colour.

## Icon Packs

Select **Icon packs** in the **Device Types** header to choose or import an icon pack. Packs are stored in your browser only, so importing or removing one doesn't change anyone else's view. NetMap cleans imported SVG icons before showing them, but only import packs from sources you trust.

## Group And Location Colours

**Group & Location Colours** sets the colour of the chips in the Inventory table for each entry in **VLANs / Groups** and **Locations**. Like device types, each has an automatic colour until you choose one, and you can reset it.
