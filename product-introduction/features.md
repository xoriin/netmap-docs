# Features

## Core Network Management

- Device inventory with create, update, delete, import, search, and favourites.
- Topology graph with devices, groups, sites, relationships, saved layouts, and shared layout import.
- Manual and scheduled nmap discovery with review-only observations.
- VLAN and topology group metadata.
- Site/location management.

## Monitoring

- Fleet summary.
- Device monitoring rows.
- Device status history and analysis.
- TCP/UDP service checks.
- Alert rules and notification delivery records.

## IPAM

- Subnet management.
- Address grid views.
- Next available address lookup.
- IP reservations.
- DHCP lease import.
- Conflict detection.
- VLAN-to-subnet suggestions and import.

## Security And Syslog

- UDP/TCP syslog ingestion.
- Separate `firewall.db` for firewall/syslog event storage.
- FTS5 raw-log search.
- Saved searches.
- Firewall event export.
- Selected-device security event summaries.

## Administration And Automation

- Local users, roles, custom permissions, and account lockout.
- OIDC SSO configuration.
- API keys using `X-API-Key`.
- SuperAdmin diagnostics.
- Database backup, restore validation, restore, and scheduled backup file management.

See also: [API Capability Matrix](../api/capability-matrix.md).
